# ia-sencilla-miguel

Enlace a la web: https://miguelsanstrujilloia-jpg.github.io/ia-sencilla-miguel/

Esto es un proyecto de Miguel Sans simplemente por entretenimiento; esta web te dice el tiempo y la hora en tu ubicación exacta, el reloj se cambia solo dependiendo de donde te encuentres al igual que el tiempo ya que utiliza tu ubicación.

ADVERTENCIA: SI NO SE ACTIVA LA UBICACIÓN NO FUNCIONA CORRECTAMENTE LA WEB.
Los datos no son recopilados en la web asique podeis estar tranquilos.
